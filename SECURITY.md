# Security policy

Only the [latest release](https://github.com/osman-butt/spring-init-tui/releases/latest) gets security fixes.

To report a vulnerability, use [Report a vulnerability](https://github.com/osman-butt/spring-init-tui/security/advisories/new) on the Security tab. The report stays private until a fix is released. Please do not open a public issue for it.
