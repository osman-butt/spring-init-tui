# spring-init-tui

A terminal UI for [Spring Initializr](https://start.spring.io), built with Go and [Bubble Tea](https://github.com/charmbracelet/bubbletea).

## Requirements

- Go 1.26 or newer

## Run

```sh
go run .
```

## Install

```sh
go install github.com/osman-butt/spring-init-tui@latest
```
